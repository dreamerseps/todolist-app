## UC-01: 회원가입 / 로그인 / 로그아웃

### SCN-01: 신규 사용자 회원가입 ✅ PASS

**정상 흐름**
- 이름/이메일/비밀번호/비밀번호 확인 폼 정상 표시
- 유효한 정보 입력 후 회원가입 클릭 → 로그인 페이지로 리다이렉트 ✅

**예외 흐름**
- 이미 가입된 이메일 입력 → "이미 사용 중인 이메일입니다." 오류 표시 ✅
- 8자 미만 비밀번호 입력 → "비밀번호는 8자 이상이어야 합니다." 오류 표시 ✅

**비고**
- 비밀번호 오류 메시지가 길이(8자)만 체크하며 대소문자·숫자·특수문자 요구사항은 메시지에 미포함 (시나리오 요구사항과 부분 불일치)

### SCN-02: 기존 사용자 로그인 ✅ PASS

**정상 흐름**
- 이메일/비밀번호 입력 후 로그인 → /todos 페이지로 이동 ✅
- 헤더에 사용자명 "E2E테스트" 표시 ✅

**예외 흐름**
- 잘못된 비밀번호 입력 → "이메일 또는 비밀번호가 일치하지 않습니다." 오류 표시 ✅

**비고**
- 인증 토큰은 Zustand 인메모리에만 저장됨 (페이지 새로고침 시 로그아웃됨)
- `page.goto()` 방식의 직접 URL 접근 시 ProtectedRoute에 의해 로그인 페이지로 리다이렉트됨 (정상 동작)

## 기타 관찰 사항

1. **인메모리 인증**: JWT 토큰이 Zustand 인메모리에만 저장되어 페이지 새로고침 시 로그아웃됨. 설계 의도이나 UX 측면에서 불편할 수 있음.
2. **URL 파라미터 필터 동기화**: 필터/정렬 상태가 URL 파라미터로 관리되어 뒤로가기 및 공유가 가능한 구조 ✅
3. **다국어 지원**: 헤더에서 한국어/English/中文/日本語/Español/Français 전환 가능 (기능 동작 확인)
4. **다크 모드**: 헤더에 다크 모드 토글 버튼 존재 (기능 동작 확인)
5. **마감일 필드**: `datetime-local` 타입으로 날짜+시간 입력 방식 (시나리오는 날짜만 명시)
6. **시간대 표시**: 마감일이 UTC 기준으로 저장되어 한국 시간과 차이 발생 (예: 10:00 KST → 01:00 표시)
