## 1. 제품 개요

### 1.1 목적

20대~50대 직장인이 업무·개인 할일을 카테고리 기반으로 체계적으로 관리할 수 있는 반응형 웹 애플리케이션.  
인증된 사용자별로 데이터를 완전 분리하여 개인 정보 보호와 보안을 보장한다.

### 1.2 핵심 가치

| 가치 | 설명 |
|------|------|
| 보안 | JWT 기반 인증으로 개인 데이터 보호 |
| 접근성 | Web · Mobile Web 반응형 UI로 어디서나 사용 가능 |
| 체계성 | 카테고리 + 필터링으로 할일 구조화 관리 |
| 확장성 | OAuth Social 인증, 다크모드, 다국어 2차 확장 대비 설계 |

| 영역 | 기술 |
|------|------|

## 8. REST API 설계 방향

### 인증

| Method | Endpoint | 설명 |
|--------|----------|------|
| POST | `/api/auth/signup` | 회원가입 |
| POST | `/api/auth/login` | 로그인 (JWT 발급) |
| POST | `/api/auth/refresh` | Access Token 재발급 |
| POST | `/api/auth/logout` | 로그아웃 |

### 사용자

| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/api/users/me` | 내 정보 조회 |
| PATCH | `/api/users/me` | 내 정보 수정 |

### 카테고리

| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/api/categories` | 카테고리 목록 조회 (기본+사용자 정의) |
| POST | `/api/categories` | 카테고리 생성 |
| PATCH | `/api/categories/:id` | 카테고리 수정 |
| DELETE | `/api/categories/:id` | 카테고리 삭제 |

### 할일

| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/api/todos?category_id=&from=&to=&is_completed=&sort=&page=&limit=` | 할일 목록 조회 (필터·정렬·페이지네이션 포함) |
| POST | `/api/todos` | 할일 등록 |
| PATCH | `/api/todos/:id` | 할일 수정 |
| DELETE | `/api/todos/:id` | 할일 삭제 |

> 모든 `/api/users`, `/api/categories`, `/api/todos` 엔드포인트는 **JWT Authorization 헤더 필수**.

## 9. 데이터 보존 정책

- 회원 탈퇴 기능은 **2차 릴리즈**에서 제공

- 소프트 딜리트(soft delete) 미적용

## 10. 인증 설계

### JWT 구조

| 토큰 | 만료 | 저장 위치 |
|------|------|----------|
| Access Token | 15분 | 메모리 (Zustand) |
| Refresh Token | 7일 | 메모리 (Zustand) |

- 두 토큰 모두 Zustand Store에 저장하며, 페이지 새로고침 시 토큰이 초기화되어 재로그인이 필요하다.
- Access Token 만료 시 Zustand의 Refresh Token으로 자동 갱신 (axios interceptor 활용)
- 로그아웃 시 Zustand Store에서 두 토큰 모두 제거

### OAuth 2차 확장 대비

- User 엔티티에 `provider` (local / google / facebook), `provider_id` 컬럼 예약 설계
- 1차에서는 `provider = 'local'`로 고정

## 12. 핵심 비즈니스 규칙 (도메인 정의서 참조)

| # | 규칙 |
|---|------|
| BR-01 | 모든 기능은 인증된 사용자만 사용 가능 |

## 13. 용어 사전

| 용어 | 영문 | 정의 |
|------|------|------|
| 할일 | Todo | 사용자가 수행해야 할 작업 단위 |
| 카테고리 | Category | 할일을 분류하기 위한 그룹 |
| 기본 카테고리 | Default Category | 시스템이 모든 사용자에게 공통 제공하는 카테고리 |
| 사용자 정의 카테고리 | Custom Category | 사용자가 직접 생성한 카테고리 |
